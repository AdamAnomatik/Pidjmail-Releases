# Поддержка / Support

## Русский

### Перед отправкой отчёта

1. Проверьте версию Pidjmail и существующие [обращения](https://github.com/AdamAnomatik/Pidjmail-Releases/issues).
2. Перезапустите приложение.
3. Определите, возникает ли проблема в демонстрации или в настоящем ящике.
4. Для подключения проверьте инструкции провайдера в настройках: IMAP и пароль приложения. Если провайдер требует OAuth, текущая версия его не поддерживает.

### Сообщить об ошибке

[Откройте форму](https://github.com/AdamAnomatik/Pidjmail-Releases/issues/new/choose) и укажите версию приложения, Windows, шаги, ожидаемый и фактический результат. Для интерфейса полезны масштаб Windows и размер окна; для почты — название провайдера без адреса и пароля. Прикладывайте только очищенные от приватных данных скриншоты.

При неопределённой доставке сначала проверьте «Отправленные» и веб-почту. Не отправляйте такое письмо повторно автоматически. Для ошибки AI достаточно названия сервиса, модели и безопасного текста ошибки; ключ не нужен.

### Запрос функции

Опишите задачу, текущий способ её решения и желаемый результат. Не прикладывайте секреты, файлы профиля и личные письма. Для уязвимостей используйте [SECURITY.md](SECURITY.md), а не публичный технический отчёт.

## English

### Before reporting

1. Check your Pidjmail version and existing [issues](https://github.com/AdamAnomatik/Pidjmail-Releases/issues).
2. Restart the application.
3. Determine whether the problem occurs in demo mode or a real account.
4. For connection issues, check the provider guide in Settings, IMAP access and the app password. Providers requiring OAuth are not supported by this release.

### Bug reports

[Open the form](https://github.com/AdamAnomatik/Pidjmail-Releases/issues/new/choose) and include the app and Windows versions, steps, expected and actual behavior. For UI issues, include Windows scaling and window size; for mail issues, the provider's name without an address or password. Remove private information from screenshots.

For uncertain delivery, check Sent and webmail before retrying. Do not automatically resend. For AI errors, include the service/model and a sanitized error message; never include the API key.

### Feature requests

Describe the task, your current workaround and the desired result. Do not attach secrets, profiles or private email. Follow [SECURITY.md](SECURITY.md) for vulnerabilities instead of posting public technical details.

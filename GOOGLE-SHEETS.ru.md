# Google Таблицы в Pidjmail

Раздел **Таблицы** показывает доступные Google-таблицы, поиск по названию и листы выбранного документа. Просмотр только для чтения: приложение не изменяет ячейки. Список загружается страницами по 100 файлов, содержимое — по 100 строк и 26 столбцов с кнопками перехода. Это размер порции, а не предел документа. Изображения, диаграммы, объединения ячеек и редактирование открывайте кнопкой браузера.

Готового общего OAuth-клиента у проекта пока нет. Один раз создайте собственный Desktop app client по инструкции ниже. Пароль Google в Pidjmail не вводится; вход открывается в системном браузере. Реальное подключение вашего аккаунта ещё не проверялось.

## Подготовка Google Cloud

1. Откройте [Google Cloud](https://console.cloud.google.com/), создайте проект и выберите его.
2. В **APIs & Services → Library** включите **Google Drive API** и **Google Sheets API**.
3. Откройте **Google Auth Platform → Branding**. При первом запуске нажмите **Get Started**, укажите название приложения, адрес поддержки и контакт разработчика.
4. В **Audience** выберите **External**, режим **Testing** и добавьте свой адрес Google в **Test users**. В организации доступ может ограничиваться администратором.
5. В **Data Access → Add or remove scopes** добавьте ровно два права:
   - `https://www.googleapis.com/auth/drive.metadata.readonly`
   - `https://www.googleapis.com/auth/spreadsheets.readonly`
6. В **Clients → Create client** выберите **Desktop app**, задайте имя и скачайте JSON. Web application и ключ сервисного аккаунта не подходят. Вручную задавать redirect URI для Desktop app не нужно.

Названия разделов и порядок создания клиента соответствуют [инструкции Google](https://developers.google.com/workspace/sheets/api/quickstart/nodejs). Приложение использует [настольный OAuth с loopback и PKCE](https://developers.google.com/identity/protocols/oauth2/native-app).

## Подключение в приложении

1. Выйдите из демонстрации и откройте **Таблицы**.
2. Нажмите **Выбрать JSON-конфигурацию OAuth** и выберите скачанный файл.
3. Нажмите **Подключить Google**, войдите в нужный аккаунт в браузере и подтвердите оба разрешения. Если подключаете собственный тестовый проект, сверяйте его имя и аккаунт с созданными вами настройками.
4. Вернитесь в Pidjmail. Откроется список таблиц. Выберите документ, затем лист. Кнопка обновления получает актуальные данные.
5. Для замены клиента сначала нажмите **Отключить Google**. Отмена входа закрывает ожидание, почтовые аккаунты при этом сохраняются.

JSON и токены хранятся только в зашифрованном профиле; интерфейс не получает их содержимое. Не отправляйте эти файлы и коды входа в чат и не добавляйте их в Git. Данные ячеек используются в памяти для просмотра и не сохраняются приложением как архив документов. Почтовый профиль и его резервные копии могут содержать зашифрованное подключение Google.

## Разрешения и возможные ошибки

Для полного списка нужны метаданные Drive, включая сведения о файлах вне таблиц; приложение запрашивает из них только id, название и время изменения Google-таблиц. Право `drive.metadata.readonly` относится к restricted scopes: готовое подключение для широкого распространения требует проверки Google. Собственный тестовый клиент предназначен для указанных тестовых пользователей. [Классификация прав Drive](https://developers.google.com/workspace/drive/api/guides/api-specific-auth).

- **Access blocked / access_denied**: проверьте Test users, выбранный проект и ограничения организации.
- **API has not been used / 403**: включите оба API в том же проекте; проверьте доступ аккаунта к документу и предоставление обоих прав.
- **Повторно войти**: разрешение отозвано или истёк refresh token. Для External/Testing с этими правами срок refresh token — 7 дней; возможны и другие причины истечения. [Срок действия токенов Google](https://developers.google.com/identity/protocols/oauth2#expiration).
- **429**: временный лимит Google, повторите позже.
- **Документ не найден**: проверьте аккаунт, доступ к файлу и корзину Drive.

При отключении Pidjmail сначала удаляет локальные токены и пытается отозвать разрешение у Google. Если сеть недоступна, приложение показывает ссылку на [подключения аккаунта Google](https://myaccount.google.com/connections), где разрешение можно удалить вручную.
